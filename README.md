FrotaSmart 🚚

Aplicação web para organizar veículos, abastecimentos e custos de uma frota. Desenvolvida com Python, Streamlit, SQLite e Pandas. Funciona no computador e no navegador do celular.

Recursos

- Cadastro e consulta de veículos, combustível e situação (ativo/inativo).
- Registro de abastecimentos com data, quilometragem, litros, valor, posto e observações.
- Validação da sequência de quilometragem, inclusive para lançamentos retroativos.
- Painel com indicadores, abastecimentos recentes e gastos por veículo.
- Relatórios por período e exportação CSV.
- Banco SQLite criado automaticamente.
- Dados fictícios opcionais para demonstração.
- Interface adaptada para telas estreitas e autenticação opcional por senha.

Tecnologias

Python · Streamlit · SQLite · Pandas

Escopo

O FrotaSmart é uma aplicação demonstrativa de portfólio para gestão básica de frota. Ainda não oferece manutenção preventiva, contas individuais, controle de permissões ou sincronização automática entre as instalações local e online.
